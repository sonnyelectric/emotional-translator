## Implement

1. On Start in Live, obtain permission on intentional activation. Use AudioWorklet to read Float32 samples, downmix, and perform band-limited or otherwise verified resampling from actual device/context rate to mono 16 kHz. Preserve continuous resampling phase. Quantize to little-endian signed PCM16, use default 40 ms frames and the exact allowed sizes, and bound worklet/output backlog.
2. Open the loopback socket after permission and send Start. Accept format only from a valid live `listening` acknowledgement. Feed validated events to C-02's reducer. On Pause and Stop cease forwarding and drain complete queued frames before sending control. Drop sub-20 ms tails. Pause suspends capture, Resume waits for the new listening ack, Stop releases mic resources. Gate the mode switch and Reset. Show clear permission, disconnection and live state.
3. Track socket generations and close tracks/context/worklet on Stop, fatal receive error, permission-flow cancellation, disconnect and unmount. Preserve existing text until Reset. Add opt-in capture endpoint/`performance.now()` diagnostics for the later latency benchmark. Keep browser config and developer output free of provider keys and captured contents.
