## Implement

1. Fetch the two local replay endpoints. Validate the whole saved stream, then schedule relative to `issued_at_ms`. Use a local clock abstraction to test ordering and remaining delay after pause/resume. Stop keeps committed content, Reset clears it and cancels pending work. Replay mode remains explicit and shows saved/synthetic provenance. Add `install:browsers` for Chromium and `test:e2e` for Playwright. Let the browser test stub fixture responses and use `E2E_REAL_REPLAY=1` to target the real local backend.
2. Build a single reusable reducer that C-03 will also use for live. Bind ID and clock, reject invalid/stale/old-session state, replace provisional text, append each commit once, patch timed words, preserve newer partials, and implement draft/update/retract/finalize by ID. Invalid known replay stops before mutating state. Invalid known live payload handling stays defensive for C-03.
3. Render the centered dark-navy transcript, approximately three current sentences, subtle provisional words, and collapsible scrollable history. Use punctuation-aware display selectors that can split one commit into multiple sentences and keep one sentence intact across adjacent commits. Preserve word IDs and segment ownership through both operations. Use stable word spans and select the exact backend anchors. Add a simple reusable SVG overlay with the correct silhouettes, size/saturation and opacity, gentle animation, and small coordinated shapes across line wraps. Measure DOM line runs at layout and resize. Keep words in front and freeze final geometry state at its anchors. A viewport change can remeasure it. Include baseline two-color blend and fades, and leave refined styling and accessible inspector for C-04.
